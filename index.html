    SETTINGS ●

    設定

    Google Cloud で YouTube Data API v3 を有効にしたキーを入れてください。ログイン中は Google ドライブにも保存され、同じアカウントの端末で共有されます。

    詳細設定

    通常は空欄のままで Google ログインできます。独自の OAuth クライアントを使う場合だけ入力してください。

    アプリとして使うホーム画面やデスクトップに追加すると、オフラインでも開けます。
    ACCOUNT ●

    アカウント

    データの保存先: Google ドライブの「ChannelViewer」フォルダー。同じアカウントでログインした端末と、チャンネルリストと設定を共有します。
